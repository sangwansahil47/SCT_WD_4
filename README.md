# Todo Application

A simple and responsive Todo Application built using HTML, CSS, JavaScript, and Local Storage.

## Features

- Add new tasks
- Set a due date for each task
- Mark tasks as completed
- Delete tasks
- Save tasks using Local Storage
- Persistent data even after page refresh
- Clean and user-friendly interface

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Bootstrap 5
- Font Awesome

## How to Use

1. Enter a task in the input field.
2. Select a due date.
3. Click **Add** to create a new task.
4. Mark tasks as completed using the checkbox.
5. Delete tasks using the trash icon.
6. Click **Save** to store tasks in Local Storage.

## Project Goal

This project demonstrates DOM manipulation, event handling, dynamic UI rendering, and browser Local Storage management using JavaScript.
